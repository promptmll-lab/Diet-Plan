# 🥗 برنامج الدايت الذكي — diet-plan

برنامج دايت عربي تفاعلي مصمم لعمر 42 / وزن 110 كجم / طول 170 سم.

- ~1900 سعرة/يوم، بروتين عالي، بدون جوع
- 7 أيام متنوعة + بدائل
- 8 ثيمات + خط Cairo بـ 8 أوزان
- عبارات تحفيزية يومية + تذكير بالإيميل
- متوافق مع WHO / البحر المتوسط / DASH

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
بعد الرفع فعّل Pages من:
`Settings → Pages → Deploy from branch → main → / (root)`

الرابط سيكون:
`https://USERNAME.github.io/diet-plan/`

⚠️ تنبيه طبي: استرشادي عام ولا يغني عن استشارة الطبيب.
